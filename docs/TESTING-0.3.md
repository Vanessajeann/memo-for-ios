# 0.3 平台功能移植验收

源码基线：Android Memo 3.2.0-beta1；最低 iOS 18，优先 iPhone 16 Pro Max / 18.6.2。

本轮检查：Core 平台解析与权限判定测试、原生录制／DASH 包一致性测试、WK observer。CI 必须归档 arm64 IPA，并编译模拟器应用，捕获四页与深色界面。模拟器截图只验证布局，不证明真实账号或直播功能。

## 真机检查顺序

1. 使用自己的证书与匹配描述文件重签 IPA，确认应用版本和 Build；不要上传证书到仓库。
2. 在设置内分别进入官方抖音／Bilibili 网页登录；完成平台验证，返回检查会话，独立退出不应影响另一平台。
3. 添加 HLS 直链、抖音直播分享、Bilibili 直播间，检查画质、静音小窗、放大、独立录制和停止全部。FLV／RTMP／RTSP 当前用于录制；预览需要 HLS。
4. 抖音作品页粘贴博主主页，网页需可见时完成验证，确认分页／自动滚动、暂停、搜索、选择、清空；图集缺页不应被当成完整下载。
5. Bilibili 输入 BV／AV／b23／UP 主页，检查分 P 和真实开放画质。不可用档位须说明原因；指定档位失效时不能自动降档。
6. 队列启动后切后台，再回前台完成 DASH 合成；断网／重开后核对完成图集页复用、暂停／重试和无重复输出。强制退出对系统下载的影响单独记录。
7. 录像页检查视频播放、图集左右滑动与缩放、批量分享到 Files、批量相册保存、多录像导入和删除；不受系统支持的格式须保留原文件。
8. 开启真实 HLS 后台收听，锁屏 10／30／120 分钟，检查文件增长、实际播放时长和声画同步；来电、其他 App 抢占音频、低电量与网络切换分开测试。

仅在合成媒体和账号实测都完成后，才能把相应条目标为“真机通过”。当前 Release 为测试版。
